# Security policy

## Supported versions

Security fixes are made for the latest released version of cp-cli.

## Reporting a vulnerability

Report vulnerabilities privately through the [GitHub security advisory form](https://github.com/keys-i/leetcode-rs/security/advisories/new). Do not include exploit details in a public issue or discussion.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Reports receive an acknowledgement after they have been reviewed.

## Response and disclosure

We aim to acknowledge a report within five business days and confirm the initial severity and next steps within ten business days. Timing for a fix depends on the impact and complexity, and we will share material progress with the reporter.

Keep an unpatched vulnerability confidential until coordinated disclosure is agreed. When appropriate, the project will publish a security advisory with affected versions, mitigations, the fixed release, and reporter credit.

## Scope

The Rust CLI, release artifacts, and repository automation are in scope. Third-party competitive-programming platforms should be reported to their respective security teams.
